# Personal portfolio QR codes

## Build
- Add a “QR code” action beside the existing portfolio link in the dashboard.
- Open an accessible preview showing a QR code for the portfolio’s current public address.
- Let the creator download a high-resolution PNG suitable for sharing or printing.
- Generate the code in the browser without sending the portfolio address to another service.

## Public messaging and SEO
- Add QR-code sharing to the homepage and pricing plan benefits.
- Mention the free personal portfolio QR code naturally on the targeted SEO pages and in their search descriptions where relevant.
- Keep the language accurate: the QR code points to the same public portfolio link and updates automatically when regenerated after an address change.

## Verification
- Check signed-in dashboard rendering, QR preview/download behavior, mobile layout, metadata, and the current build.
