# Studio backdrop photographs

These locally bundled 2K photographic surface scans are by Poly Haven and are
released under CC0 (public domain). They can be used commercially. The JPEGs
are resized/compressed for browser use; no external request is needed when
someone selects a backdrop.

- warm-wood.jpg: https://polyhaven.com/a/wood_table_001
- light-wood.jpg: https://polyhaven.com/a/wood_table
- License: https://polyhaven.com/license

Downloaded 1 October 2026 from each asset's 2K Diffuse JPG using the public
https://api.polyhaven.com/files/<asset> manifest.

Studio uses a locally generated HDR room environment (Three.js RoomEnvironment),
prefiltered for image-based lighting. Paper, covers and photographic backdrop
share this environment; a restrained key light adds soft contact shadows.
